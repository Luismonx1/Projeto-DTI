# 🎬 Sistema de Gerenciamento de Filmes (CRUD com SQLite)

Este projeto é um sistema de gerenciamento de filmes em C#, executado no console, que utiliza um banco de dados SQLite para armazenar e manipular informações de filmes.

O sistema permite realizar operações completas de CRUD (Criar, Ler, Atualizar e Excluir), simulando um pequeno sistema de cadastro persistente em banco de dados.

# 📌 Objetivo do Projeto

 O objetivo deste projeto é praticar e consolidar conhecimentos em:

* Programação em C#

* Manipulação de banco de dados SQLite

* Operações CRUD

* Uso de menus interativos no console

* Organização e reutilização de métodos

* Tratamento de erros e validações de entrada

* Projeto desenvolvido com fins educacionais.

# ⚙️ Funcionalidades

🔵 Cadastrar Filme

* Nome

* Data de lançamento

* Descrição (opcional)

🔵 Excluir Filme

* Remoção de filmes pelo ID

🔵 Alterar Filme

* Atualização de nome, data e descrição

🔵 Listar Filmes

* Exibição de todos os filmes cadastrados

🔵 Procurar Filme

* Busca de filme pelo ID

# 🛠️ Tecnologias e Ferramentas Utilizadas

* C#

* .NET

* SQLite

* Biblioteca Microsoft.Data.Sqlite

* Console Application

* SQL (CREATE, INSERT, SELECT, UPDATE, DELETE)
